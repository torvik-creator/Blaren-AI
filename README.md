# TaskFlow

TaskFlow is a minimal, fast, and responsive task management web app built with Node.js, Express, and MongoDB. Designed for individual productivity, TaskFlow helps users create, track, and organize tasks effortlessly with clean UI and simple controls.

## 🚀 Features

- ✅ Create, update, and delete tasks
- 🗂️ Organize tasks into custom categories
- 🔔 Set due dates and receive reminders
- 📊 View task progress via dashboard
- 🔒 User authentication with JWT tokens
- 📱 Mobile-friendly responsive design

## 🔧 Tech Stack

- **Frontend**: HTML, CSS, JavaScript (Vanilla)
- **Backend**: Node.js, Express
- **Database**: MongoDB (with Mongoose)
- **Authentication**: JSON Web Tokens (JWT)
- **Deployment**: Render & MongoDB Atlas
